# Roadmap

- Windows host for the UI shell: WinUI 3 (C#) over T12's C ABI, the editor surface from T12.2 in a `SwapChainPanel`, looking like Visual Studio's editor: Cascadia Mono, Visual Studio's Light and Dark themes, WinUI caret and selection, Visual Studio shortcuts (approved by the creator with T12's native direction).
- Linux host for the UI shell: GTK 4 over T12's C ABI, the editor surface from T12.2 (approved by the creator with T12's native direction).
