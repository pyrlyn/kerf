# T19.1. UI Kit foundations and controls

A `KerfUI` SwiftPM target with no Rust dependency: colour and size tokens from the Figma variables, the text styles mapped to the system fonts (SF Pro for Inter, SF Mono for Roboto Mono), the 16 px stroke icons, and the "Controls" frame as AppKit views: Button (Primary, Secondary, Destructive, Destructive outline, Ghost; Small, Regular, Large), Chip, Status, Key, Switch, Text field, Icon button, Checkbox, Select, Segmented control, Count badge, Avatar, Spinner and Progress bar. `Kerf --ui-kit` opens a gallery window. Done when `swift test` renders every control offscreen and checks its size and its sampled colours against the tokens.

Plan: 1. `macos/Sources/KerfUI/Tokens.swift` and `Typography.swift` generated by hand from the Figma variables and text styles. 2. `Icons.swift`: the icons' SVG path data drawn with `NSBezierPath` (SwiftPM's `swift build` does not compile asset catalogs). 3. One file per control family under `macos/Sources/KerfUI/Controls/`. 4. The gallery behind `--ui-kit` in `Sources/Kerf`. 5. `Tests/KerfUITests`: sizes and pixel samples per control. Verify with `swift build`, `swift test` and `swift-format lint --strict`.
